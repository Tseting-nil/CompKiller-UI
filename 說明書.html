建立視窗

參數類型說明
Namestring左上角顯示名稱
Keybindstring鍵盤快速開關 UI
Logostring,BooleanUI 左上角 Icon {ID, 顯示}
Scalefunction根據設備自動選擇 UI 大小
TextSizenumber自訂 UI 文字大小（全域）
default_Togglestring"on" 加載時執行 Callback，"off" 不執行（預設）
 
local Window = Compkiller.new({
    Name = "Compkiller UI",
    Keybind = "LeftAlt",
    Logo = {"rbxassetid://15307540148", true},
    Scale = Compkiller:_UseSmallUI() and Compkiller.Scale.Mobile or Compkiller.Scale.Window,
    TextSize = 15,
    default_Toggle = "off",
});

視窗控制方法

方法說明
Window:SetVisible(bool)控制 UI 的顯示 / 隱藏
Window:Toggle(bool)切換 UI 的開關狀態
Window:Destroy()完全銷毀 UI（不可逆）
Compkiller:Unload()卸載函式庫建立的所有 UI 並釋放資源
Window:SetLocked(bool)固定 / 解除固定 UI 位置（禁止 / 允許拖動）
Window:IsLocked()獲取 UI 是否處於固定（無法移動）狀態
Window:Update(config)更新左下角用戶資訊欄及視窗標題
 
Window:Destroy()          -- 銷毀目前視窗
Compkiller:Unload()       -- 卸載所有 UI（建議在腳本重載前調用）

Window:SetLocked(true)    -- 固定 UI，禁止拖動
Window:SetLocked(false)   -- 解除固定，允許拖動
print(Window:IsLocked())  -- 輸出是否固定（true/false）

-- 搭配 Toggle 動態控制
Section:AddToggle({
    Name = "鎖定UI位置",
    Default = false,
    Callback = function(Value)
        Window:SetLocked(Value)
    end,
})

Window:Update — 左下角用戶資訊

控制左側欄底部的用戶資訊區塊（頭像、名稱、過期日期）及視窗標題。未傳入的欄位保持預設值。

參數類型說明預設值
Usernamestring左下角顯示的用戶名稱玩家的 DisplayName
ExpireDatestring左下角顯示的過期日期"NEVER"
UserProfilestring左下角頭像圖片（rbxassetid 或縮圖 URL）玩家頭像縮圖
Logostring左側欄頂部的 Logo 圖示建立視窗時傳入的 Logo
WindowNamestring左側欄頂部的視窗標題建立視窗時傳入的 Name
 
Window:Update({
    Username = "玩家名稱",
    ExpireDate = "2025/12/31",
    UserProfile = "rbxassetid://xxxxx",
    Logo = "rbxassetid://xxxxx",
    WindowName = "我的腳本",
})

Window.UserSettings — 左下角浮動設定面板

點擊左下角用戶資訊區塊時彈出的浮動面板（235px 寬，高度自動撐開）。呼叫 :Create() 後方可使用，且必須在建立標籤之前呼叫。

方法說明
Window.UserSettings:Create()初始化面板，回傳 Section（可新增 UI 元件）
Window.UserSettings:Window(bool)手動顯示 / 隱藏面板（需先呼叫 Create）
 
-- 初始化並在面板內加入元件
local UserPanel = Window.UserSettings:Create()
UserPanel:AddToggle({
    Name = "設定選項",
    Default = false,
    Callback = function(Value) end,
})

-- 手動控制顯示
Window.UserSettings:Window(true)   -- 開啟
Window.UserSettings:Window(false)  -- 關閉

元件通用方法

所有 UI 元件都支援 SetVisible(bool) 和 GetVisible() 來控制顯示狀態。

local slider = Section:AddSlider({ ... })
slider:SetVisible(false) -- 預設隱藏

local toggle = Section:AddToggle({
    Name = "顯示進階",
    Default = false,
    Callback = function(v) slider:SetVisible(v) end
})

支援的元件： Section、AddToggle、AddSlider、AddButton、AddButtonRow、AddDropdown、AddKeybind、AddColorPicker、AddLabel、AddParagraph、AddTextBox、AddInputText、AddInputNum

配置管理器

參數類型必填預設值說明
RootDirectorystring✗nil自訂配置儲存根目錄；設定時優先於 Directory
Directorystring✗Compkiller舊版根目錄參數，保留向下相容
Configstring✗Software根目錄內的配置子目錄
AutoLoadboolean✗false設定分頁初始化時載入上次選擇的配置
 
local ConfigManager = Compkiller:ConfigManager({
    RootDirectory = "Compkiller-UI/Saves",
    Config = "Example-Configs",
    AutoLoad = true,
});

實際配置路徑為 RootDirectory/Config。舊程式仍可使用 Directory，但新程式建議改用語意較明確的 RootDirectory。

執行期間修改儲存位置

-- 只切換根目錄，沿用目前的配置子目錄
local Success, ErrorMessage = ConfigManager:SetRootDirectory("MyHub/Saves")

-- 同時切換根目錄與配置子目錄
ConfigManager:SetRootDirectory("MyHub/Saves", "AnimeAura")

-- 只切換配置子目錄
ConfigManager:SetConfigDirectory("AnotherGame")

切換儲存位置只會讓管理器改用新路徑並建立所需目錄，不會搬移、複製或刪除舊目錄中的配置。切換後 AutoLoadLastConfig() 可再次嘗試載入新路徑中的上次配置。

建立設定分頁 (DrawConfig)

local ConfigUI = Window:DrawConfig({
    Name = "設定",
    Icon = "folder",
    Config = ConfigManager,
});
ConfigUI:Init();

當 AutoLoad = true 時，使用者按下設定項目的 Load 後，該配置會成為「上次選擇的配置」；下次執行 ConfigUI:Init() 時會自動載入一次。記錄保存在隱藏的 __last_config.json 中，不會出現在配置清單或配置數量內。

若要在內建設定分頁修改名稱，先在 Config Name 輸入新名稱，再按目標配置右側的鉛筆按鈕。改名後，上次配置記錄也會同步更新。
