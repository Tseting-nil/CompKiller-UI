## 建立視窗

| 參數             | 類型           | 說明                                                     |
| ---------------- | -------------- | -------------------------------------------------------- |
| `Name`           | string         | 左上角顯示名稱                                           |
| `Keybind`        | string         | 電腦端鍵盤快速開關 UI                                    |
| `Logo`           | string,Boolean | UI 左上角 Icon `{ID, 顯示}`                              |
| `Scale`          | function       | 根據設備自動選擇 UI 大小（別動）                         |
| `TextSize`       | number         | 自訂 UI 文字大小（全域）                                 |
| `default_Toggle` | string         | `"on"` 加載時執行 Callback， `"off"` 不執行（預設）      |

```lua
local Window = Compkiller.new({
    Name = "Compkiller UI",
    Keybind = "LeftAlt",
    Logo = {"rbxassetid://15307540148", true},
    Scale = Compkiller:_UseSmallUI() and Compkiller.Scale.Mobile or Compkiller.Scale.Window,
    TextSize = 15,
    default_Toggle = "off",
});
```

## 視窗控制方法

| 方法                       | 說明                                    |
| -------------------------- | --------------------------------------- |
| `Window:SetVisible(bool)`  | 控制 UI 的顯示 / 隱藏                  |
| `Window:Toggle(bool)`      | 切換 UI 的開關狀態                      |
| `Window:Destroy()`         | 完全銷毀 UI，釋放所有資源（不可逆）     |
| `Window:SetLocked(bool)`   | 固定 / 解除固定 UI 位置（禁止/允許拖動）|
| `Window:IsLocked()`        | 獲取 UI 是否處於固定（無法移動）狀態   |
| `Window:Update(config)`    | 更新左下角用戶資訊欄及視窗標題         |

```lua
Window:SetVisible(false)  -- 隱藏
Window:Toggle(true)       -- 開啟
Window:Destroy()          -- 銷毀

Window:SetLocked(true)    -- 固定 UI，禁止拖動
Window:SetLocked(false)   -- 解除固定，允許拖動
print(Window:IsLocked())  -- 輸出是否固定（true/false）

-- 搭配 Toggle 動態控制
Section:AddToggle({
    Name = "鎖定UI位置",
    Default = false,
    Callback = function(Value)
        Window:SetLocked(Value)
    end,
})
```

### Window:Update — 左下角用戶資訊

控制左側欄底部的用戶資訊區塊（頭像、名稱、過期日期）及視窗標題。未傳入的欄位保持預設值。

| 參數          | 類型   | 說明                                       | 預設值                |
| ------------- | ------ | ------------------------------------------ | --------------------- |
| `Username`    | string | 左下角顯示的用戶名稱                       | 玩家的 `DisplayName`  |
| `ExpireDate`  | string | 左下角顯示的過期日期                       | `"NEVER"`             |
| `UserProfile` | string | 左下角頭像圖片（rbxassetid 或縮圖 URL）    | 玩家頭像縮圖          |
| `Logo`        | string | 左側欄頂部的 Logo 圖示                     | 建立視窗時傳入的 Logo |
| `WindowName`  | string | 左側欄頂部的視窗標題                       | 建立視窗時傳入的 Name |

```lua
Window:Update({
    Username = "玩家名稱",
    ExpireDate = "2025/12/31",
    UserProfile = "rbxassetid://xxxxx",
    Logo = "rbxassetid://xxxxx",
    WindowName = "我的腳本",
})
```

### Window.UserSettings — 左下角浮動設定面板

點擊左下角用戶資訊區塊時彈出的浮動面板（235px 寬，高度自動撐開）。呼叫 `:Create()` 後方可使用，且必須在建立標籤之前呼叫。

| 方法                                 | 說明                                         |
| ------------------------------------ | -------------------------------------------- |
| `Window.UserSettings:Create()`       | 初始化面板，回傳 Section（可新增 UI 元件）   |
| `Window.UserSettings:Window(bool)`   | 手動顯示 / 隱藏面板（需先呼叫 Create）       |

```lua
-- 初始化並在面板內加入元件
local UserPanel = Window.UserSettings:Create()
UserPanel:AddToggle({
    Name = "設定選項",
    Default = false,
    Callback = function(Value) end,
})

-- 手動控制顯示
Window.UserSettings:Window(true)   -- 開啟
Window.UserSettings:Window(false)  -- 關閉
```

## 介面結構

### DrawCategory — 左側標籤類別

```lua
Window:DrawCategory({ Name = "標籤名稱" });
```

### DrawTab — 左側標籤

| 參數              | 類型    | 說明                                                  |
| ----------------- | ------- | ----------------------------------------------------- |
| `Name`            | string  | 名稱                                                  |
| `Icon`            | string  | 圖示（來源: [lucide.dev/icons](https://lucide.dev/icons)） |
| `Type`            | string  | `"Single"` 單選項卡 / `"Double"` 雙選項卡（預設）     |
| `EnableScrolling` | boolean | 是否啟用滾動（建議開啟，僅 Single）                   |

```lua
local NormalTab = Window:DrawTab({
    Name = "範例分頁",
    Icon = "apple",
});
```

### DrawSection — 右側選項卡

| 參數          | 類型    | 說明                                      |
| ------------- | ------- | ----------------------------------------- |
| `Name`        | string  | 名稱                                      |
| `Position`    | string  | `"left"` 或 `"right"`（Single 無法使用）  |
| `Canclose`    | boolean | 是否顯示關閉按鈕（預設 `true`）           |
| `DefaultOpen` | boolean | 預設是否展開（預設 `true`）               |

```lua
local NormalSection = NormalTab:DrawSection({
    Name = "Section",
    Position = "left",
    Canclose = true,
    DefaultOpen = false,  -- 預設收合
});
```

**Section 方法：** `SetVisible(bool)` `GetVisible()`

### DrawContainerTab — 右側容器選項卡

| 參數   | 類型   | 說明       |
| ------ | ------ | ---------- |
| `Name` | string | 名稱       |
| `Icon` | string | 圖示       |

> 在容器選項卡內建立 `DrawTab` 會顯示在上方。

```lua
local ContainerTab = Window:DrawContainerTab({ Name = "Extract Tabs", Icon = "contact" });
local ExtractTab = ContainerTab:DrawTab({ Name = "Tab 1", Type = "Double" });
```

## 元件通用方法

所有 UI 元件都支援以下方法來控制顯示狀態：

| 方法              | 說明                         |
| ----------------- | ---------------------------- |
| `SetVisible(bool)` | 設定元件顯示 / 隱藏         |
| `GetVisible()`     | 獲取元件當前是否可見         |

**特性：** 即時生效、狀態保留、支援層級控制（可控制整個 Section）

```lua
-- 根據條件動態顯示/隱藏
local advancedSlider = Section:AddSlider({ ... })
advancedSlider:SetVisible(false)  -- 預設隱藏

local toggle = Section:AddToggle({
    Name = "顯示進階設定",
    Default = false,
    Callback = function(value)
        advancedSlider:SetVisible(value)
    end
})
```

**支援的元件：** Section、AddToggle、AddSlider、AddButton、AddButtonRow、AddDropdown、AddKeybind、AddColorPicker、AddLabel、AddParagraph、AddTextBox、AddInputText、AddInputNum

| --------------------------------------- | -------------------- |
| `WriteConfig({ Name, Author })`        | 寫入設定檔           |
| `LoadConfig("<名稱>")`                 | 載入設定檔           |
| `DeleteConfig("<名稱>")`               | 刪除設定檔           |
| `ReadInfo("<名稱>")`                   | 讀取設定檔資訊       |
| `GetConfigs()`                          | 取得所有設定檔       |
| `.Directory`                            | 設定檔目錄路徑       |

### 建立設定分頁 (DrawConfig)

| 參數     | 類型   | 必填 | 說明           |
| -------- | ------ | ---- | -------------- |
| `Name`   | string | ✓    | 分頁名稱       |
| `Icon`   | string | ✓    | 圖示           |
| `Config` | object | ✓    | ConfigManager  |

```lua
local ConfigUI = Window:DrawConfig({
    Name = "設定",
    Icon = "folder",
    Config = ConfigManager,
});
ConfigUI:Init();
```
